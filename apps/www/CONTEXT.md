# Showcase Bounded Context (`apps/www`)

Glossary and canonical definitions for the Sulaf documentation website and showcase application.

## Domain Terms

### Showcase Application

The Nuxt/Nitro application responsible for serving the documentation website, component visual demos, and the public JSON API endpoints.

### Interactive Preview

An interactive live render of a component or block within the documentation, allowing users to inspect variations, code snippets, and props.

### Registry Public Endpoint

The public URL route structure (served under `/r/...` or `/r/components/...`) exposing `registry.json`, `all.json`, and individual component JSON definitions to CLI tools and web clients.
