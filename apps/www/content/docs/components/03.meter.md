::callout{type="warning" title="Deprecated Component"}
The **Meter** component is **deprecated** and has been removed from the `@sulaf/registry`.

For progress indicators, gauges, and range visualization, use the official **[shadcn-vue Progress](https://shadcn-vue.com/docs/components/progress)** component instead.
::
