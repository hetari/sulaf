# Playground Bounded Context (`apps/playground`)

Glossary and canonical definitions for the Sulaf Playground development sandbox.

## Domain Terms

### Sandbox Application

The internal Vite + Vue application dedicated to isolated component development, interactive visual testing, and rapid prototyping before components are registered or showcased.

### Component Test Harness

Isolated routes and workspace pages within the sandbox used to exercise component reactivity, variants, props, slot compositions, and edge cases in a local development runtime.
